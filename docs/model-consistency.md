# 物性与模型一致性门槛

适用于材料选择、论文公式录入、新建边界和模型对照。这里规定 Agent 的检查职责，不表示 MCP 已实现自动拦截器。不要求为只读审计重建或求解模型。

## 1. 材料来源先于输入冻结

- 常规材料且论文没有明确指定自定义模型时，优先查本机 COMSOL 中匹配材料、相态和工况的库条目，复用经核验的完整函数，不自行编造常数或手抄简化公式。若论文明确采用不同模型，以有证据的方法为准；材料库不是永远正确或永远优先。
- 论文写明物性来自 COMSOL、某标准或某数据库时，沿该线索核对实际来源。查同版本库条目或官方案例与文档，记录来源版本、属性组、完整函数/分段、单位、温度压力范围及所选域。不凭 “Water, liquid” 标签就断言未经修改，不从标签推断作者的鼠标操作历史。
- 对照三个独立对象：论文印刷表达式、参考模型实际表达式、材料库/原始来源表达式。明确区分“系数文本不同”“代入值不同”“本构模型不同”和“来源未证实”，不能把前两者直接写成作者擅自改变物性。
- 打印系数与库系数疑似同源时，核查有效数字/截断、单位、温标及分段。高阶多项式可能因项间抵消放大舍入误差，不能把少数有效数字重新录入当作完整函数。不得只用单点反推全套系数。
- 在工作区间的代表点、端点及分段过渡处检查数量级、单位、正值、趋势和有效范围；温区未知则记录假设和限制。对敏感公式用高精度离线算术复核，且与库函数有效定义比较。直接模型评价与离线公式复算必须分别标识；平滑分段端点不能冒称精确 API 点值。
- 显著不合理的输入不得通过“设置已核验/物性已验证”门槛。优先排查录入、单位和精度后再做昂贵计算。用户明确要求执行印刷公式时可以保留探索分支，但必须标注异常与受影响结论，不把有出处等同于物理可信。
- 已有证据支持完整库函数时，记录采用依据、与印刷式差异及新规格版本后使用；无需为正常核验反复询问。严格盲测若排除某来源，遵守该范围，另列不可使用的参考信息，不污染盲测。不能自行扩大盲测限制到用户未禁止的官方软件资料，也不能默默更改已冻结历史分支。
- MCP 若没有可验证的库加载路径，应记录限制，必要时从有来源的完整表达式重建材料并标明“显式重建”，不能称为已直接载入材料库。所有 COMSOL 操作仍通过 MCP。

## 2. API 与警告门槛

新建物理节点先确定当前版本/模块的有效类型，创建后回读，不根据显示名猜类型。检查 active、父链、选择集、属性和诊断；能运行不等于未过时。已知过时节点不得作为新建模型的默认实现。

对每条相关警告记录节点、原文、类别、影响判断与处置证据。旧特征、无效选择、网格退化、求解失败分别处理。某读取接口未返回警告不能证明 GUI 无警告；保留诊断覆盖限制，不用空列表宣称全通过。

旧模型修复在副本上进行。迁移必须核对参数含义、默认值、覆盖关系和最终边界形式；如已授权求解，再比较守恒及目标量。不能仅改标签、删除警告或替换类型后宣布数值问题解决。示例见 [API 经验](api-patterns.md)。

## 3. 对照前的模型事实表

先锁定原文件哈希/版本、当前会话、研究/参数点和解状态；磁盘预求解文件不能冒充用户今天未保存的求解状态。对照记录至少涵盖影响目标量的下列项目：

| 对象 | 比较事实 | 禁止的替代判断 |
|---|---|---|
| 工况 | 入口速度/流量、热载荷、温度压力及参数索引 | 用不同工况的色带直接判复现偏差 |
| 几何 | 尺寸、固体/流体体积、底板厚度、通道截面、开口位置/面积、连通性、坐标变换 | 建模树不同就是几何错误；体积相同就是几何完全等价 |
| 物理 | 域映射、流固耦合、壁面、入口出口的数学形式及湍流条件 | 数值相同或菜单名称相似就判边界等价 |
| 网格 | 域/边界/边单元统计口径、单元类型/阶次、实际尺寸、边界层、目标量加密变化 | 自由度等于网格数；同一自动级别保证同一网格；单元数匹配即网格无关 |
| 后处理 | 解/数据集、变量/单位、选区、切面法向与位置、色带范围/分度、相机与镜像/平移 | 只统一图例就判结果一致；切片不同就判方程不同 |

几何构造可以不同，只要最终事实与物理等价有证据。参考文件与论文尺寸冲突时保留双方来源，明确当前复现对象，不为匹配曲线擅自选一种。查询失败或截断的项目保留“未验证”，不算作通过。

## 4. 差异的归因与验收

分别报告已确认差异、可能影响、因果证据与未决项。多个设置同时不同时，不能按截图或量级推断各项贡献；在已授权预算内开展可归因的单因素/有设计的对照。

工况不一致、异常物性、未处置的重要警告、缺失解身份或未过的网格门槛，阻止相应目标被判 PASS；不是一律阻止保留失败证据或授权的探索性计算。规则修改不自动修好已有 MPH，也不自动触发重算。最终应分别报告 skill 已修改、模型是否迁移及仿真是否重新验证。
