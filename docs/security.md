# Access and data handling
This is a trusted local automation service, not a security sandbox. Keep arbitrary code disabled unless needed by the authorized operator. Use local stdio or authenticated HTTP/SSE; never place bearer tokens in shared logs, URLs or source archives.

Keep research outputs outside the skill. Output confinement is a consistency guard against accidental traversal and existing junctions, not protection against an adversary concurrently rewriting the filesystem or executing arbitrary Python. Preserve unknown models and do not clear the server on routine disconnects.
