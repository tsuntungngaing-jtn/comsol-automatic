# Research execution and editable delivery
Separate the reference baseline, modified geometry and paper target. Build editable COMSOL nodes through MCP and retain parameter/material/selection names. Read-only Inspector describes actual state; it does not establish scientific validity.

After authorized work, inspect the final model, save to the user's workspace, independently reopen and re-evaluate defined observables. Deliver MPH, model name, server port, parameter/source records, warnings and remaining validation gaps. The user manually imports the tracked model into Desktop. Script-generated native nodes remain editable; this does not imply an imported mesh or external file becomes a parametric geometry.
