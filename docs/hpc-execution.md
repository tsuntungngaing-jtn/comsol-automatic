# HPC handoff
No cluster connector is provided or implied. Use only available tools and explicitly authorized accounts/resources. Record version/build, module requirements, cores/memory, batch command, input hashes, output directory and requested observables in a handoff manifest.

Confirm job identity before submitting. If submission status is unknown, recover/query it before retrying to avoid duplicate jobs. Monitor through actual scheduler or MCP capabilities. Retrieve logs, exit status, model files and result identities before accepting outputs. Do not upload research data or credentials without authorization.
