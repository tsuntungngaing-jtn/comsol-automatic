# Skill discovery is separate from MCP
The English skill folder is comsol-automatic-6-4-en. Copy/upload the complete folder through the client's supported mechanism. Installation into a filesystem location does not establish visibility in every client's management screen. Configure the MCP connector separately and verify tool listing/status without assuming successful COMSOL licensing.

The package is side-by-side by default. Do not overwrite an existing skill, environment, token or connector during discovery troubleshooting. Use the installation guide and preserve local configuration.
