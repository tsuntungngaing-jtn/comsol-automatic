# COMSOL / Fluent 论文复刻任务 prompt

将本文件全文交给仿真机 agent，填写任务卡。Paper2Simu skill 提供连接、建模、执行和留证能力；本 prompt 定义本次复刻的推理与验收。门槛是项目选择，不是厂商通用标准。本 prompt 不应随 skill 自动激活。

## 任务卡

- 软件（COMSOL / Fluent 二选一）、主机、MCP provider/session、版本及模块：……
- 原文、补充/勘误、已有模型及可用外部来源：……
- 目标工况、重建范围、简化条件、输出目录：……
- 主要指标：逐项记录唯一 id（包含工况）、论文参考值、单位、页/表/图、位置、时间窗口、平均/积分定义及归一化方式。
- 默认论文指标容差：每个指定主要指标、每个指定工况相对误差 **严格小于15%**；可在运行前显式覆盖。
- 零值/近零范围与绝对容差：按指标预先填写。
- 守恒：适用方程、边界、源/汇、储存、时间范围、归一化尺度、容差及理由：……
- 网格/时间步：目标指标、加密方案、判据及理由：……
- 预算：运行时限、内存/核数、最大求解数、修复轮次、网格及敏感性预算：……
- 已授权的运行、条件假设、输出和可逆修复范围：……

科学容差未填时，不暗中使用通用常数。agent 应根据量纲、指标用途、预期精度和算力提出有理由的值，在观察比较结果前固定。预算缺失时先提出保守且可编辑的预算，继续授权范围内的独立准备。需要用户决定的关键范围或授权保持待确认，时间经过不代表同意。

## 目标与状态

尽可能完成可信、可追溯、可继续运行的重建，不要求文章提供全部软件设置。分别报告：执行及原生终止；数值/物理检查；逐点论文匹配；直接复刻/条件复刻/校准结果。

每项检查用 PASS / FAIL / BLOCKED / NOT_RUN 并附证据。没有预定判据只报告数值，不报 PASS。求解完成不等于复刻通过；指标达标而必要检查缺失，应报告“指标达到，验证未完成”。原生求解失败不能被条件通过覆盖。只有所有声明必要检查和主要指标满足要求，才可在明确范围内声称通过。条件复刻不得包装成原文真实设置。主动跳过记 SCOPE_CHANGED，未执行记 NOT_RUN。

## 缺失信息：合理推理并继续

建立输入台账：对象/工况、值/单位、出处、来源类型、推导、适用范围、限制及影响任务。区分 paper_reported、derived、software_documented、external_reference、inferred、fitted。

依次检查原文/作者补充与勘误；由已知几何、定义、量纲、守恒或无量纲关系推导（展示公式和条件）；安装版本官方文档/材料库及权威物性；相关权威论文的适用范围；最后给出有物理依据的有界假设和场景。明确文字表格优先于同一量的示意图估计，但要核对对象/工况。软件默认不等于作者设置。曲线数字化保留误差，示意图不充当精确尺寸。

问题可定义且已授权时继续条件建模，不因“非原文直接给出”放弃。可解释、低影响的补充可按任务授权采用；影响未知时不得冒称低影响。可能改变结论的缺失量优先做预算内端点/场景敏感性，报告对主要指标和15%判断的影响。多组参数均匹配时说明不可辨识，不宣称找回原参数。

关键量无法给出合理范围或无法定义方程/边界时，集中询问，只阻塞依赖它的操作，继续其他准备或工况。校准需记录拟合变量、范围、目标数据和尝试次数；拟合数据不能再次作为独立验证，需独立工况/留出数据。不得为通过而事后改参考、删点、改平均方式或无依据调参。

## 原生求解与稳定性

以实际配置并观察到的商业软件原生停止标准为迭代收敛依据，保存配置、停止原因、日志、警告和主要物理量监控。完成任务、写出文件、退出码成功不自动等于收敛。

不附加无出处的统一残差门槛。额外残差/平台诊断用于排查，只有本任务事前明确要求才成为验收条件。检查目标量随迭代/时间的变化；非定常/周期问题用预定统计窗口，不要求非稳态物理量恒定。明显发散、非物理解或统计状态不足时记录问题并在预算内诊断。

## 守恒：检查当前模型自身

比较当前模型进出通量、源/汇和储存，不要求匹配论文未公开的守恒残差。质量、能量等分别记账，包含适用的导热、对流、辐射、相变、压力/功、瞬态储能，说明符号单位。核对原生通量提取的边界、域和精度。

声明平衡缺口和非零且物理合理的归一化尺度；净输入接近零时不用其作分母。容差按用途事前确定，不自动采用论文匹配15%，也不默认10%/20%。缺项不当零，未提取不当通过。不能仅凭简化焓差与热源不符就断言耦合错误。明显无法解释的不平衡需要诊断，能求解不能豁免。

## 网格与时间离散

预算内先比较两套有实质加密且物理设置一致的网格，记录单元/自由度、局部分辨率/壁面处理及全部主要指标变化。称为网格敏感性；两套网格不自动给出GCI、离散误差区间或网格无关性证明。

变化较大、非单调、接近15%边界或结论改变时，按预算增加网格/时间步检查，或如实报告不确定。不能选择最接近论文的网格来宣称验证。计算GCI/拟合不确定度时另行满足该方法条件；普通复刻不自动要求特定方法论文的所有网格配置。非定常结果按目标量考虑时间步敏感性，预算不足不能伪造通过。

## 逐点论文误差

非近零且适合相对比较的参考值：

`relative_error = abs(simulation - reference) / abs(reference)`

每个指定指标/工况要求 `< 0.15` 或任务卡显式覆盖值；等于门槛不通过。不能用平均误差掩盖超限点。曲线取点、对齐、插值事前固定。温度事前声明绝对温度还是温升，不能借摄氏零点或换单位改变误差。

零值/近零参考使用预定绝对容差及单位；无有效判据记 NOT_RUN，不能除零或临时挑分母。来源不确定性、数字化误差、输入假设、离散敏感性分别报告，未经依据不合并总误差。即使单点低于15%，也说明合理输入范围是否跨越门槛。

## 执行、恢复和交付

使用已选MCP路线，核查实际选区、边界、材料、耦合及结果身份。遵守预算，保留失败基线；修复记录修改、理由和受影响检查。参数/网格变动后重做依赖检查，不混用旧数据、不覆盖原始材料、不干扰他人任务。

交付原生模型（含有价值的失败/部分模型）、实际调用/脚本、日志、参数来源台账、逐点对比表、守恒收支、网格/时间步比较、假设敏感性、未解决问题及继续运行设置。附run/model/mesh/study/solution/dataset身份和文件校验信息。重开未执行写NOT_RUN；不只交截图或一句PASS。

最终报告：执行结果、证据与假设、主要指标误差、检查结果、条件与未验证项、文件清单。检索token节省、RSI改进、软件开发验收只在另行要求且实测时报告。
